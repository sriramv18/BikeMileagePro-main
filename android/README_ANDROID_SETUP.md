# Android setup notes

Create the Android host with `flutter create . --platforms=android` from the repository root if the `android/` folder is not generated by your local Flutter SDK. Then merge the manifest permissions below into `android/app/src/main/AndroidManifest.xml`.

Required permissions for current foreground GPS prototype:
- ACCESS_FINE_LOCATION
- ACCESS_COARSE_LOCATION

For a production background-tracking release, add and implement the Android foreground service with `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_LOCATION`, `ACCESS_BACKGROUND_LOCATION` where legally/technically justified, a persistent notification channel, lifecycle recovery and Play policy disclosures. Do not simply add background permissions without implementing the service and disclosure flow.

Google Maps: add your Maps SDK API key to the Android manifest under `<application>` using a secure CI secret or local secrets file. The route screen needs a valid Maps key.
